# Privacy Policy for +简 Tabs

Last updated: 2026-07-31

+简 Tabs is a browser new tab extension designed to provide a simple, customizable search experience.

## Data Stored by the Extension

The extension may store the following data locally in the user's browser:

- User settings, such as theme preference, selected search engine, and whether search results open in a new window.
- Search engine list and ordering.
- Search history, only when the user enables the search records feature.
- A custom background image, only when the user uploads one.

## How Data Is Used

This data is used only to provide the extension's new tab features, including search engine selection, customization, search history, and appearance settings.

## Data Sharing

+简 Tabs does not sell, share, transmit, or disclose user data to the developer or third parties.

## Remote Servers

+简 Tabs does not upload settings, search history, or custom background images to any remote server.

When a user submits a search, the browser navigates to the selected search engine using the query entered by the user. That request is handled by the selected search engine according to its own privacy policy.

## Data Deletion

Users can delete individual search history items in the extension interface. Users can also disable search records, clear custom backgrounds, or remove the extension to delete extension-managed local data from the browser.

## Permissions

+简 Tabs requests the `storage` permission to save user preferences, search engine configuration, search history, and custom background data locally in the browser.

## Contact

For questions about this privacy policy, please contact the developer through the Chrome Web Store listing or the project repository.
